Expérience aléatoire Univers Nombre d'éléments dans \(\Omega\) Événements Nombre total d'événements
Jet d'un dé de six faces \(\Omega = \{1, 2, 3, 4, 5, 6\}\) \(n = 6\)
  • L'issue est impaire : \(\{1, 3, 5\}\)
  • L'issue est inférieure à trois : \(\{1, 2\}\)
  • Lister les événements élémentaires : \(\{1\}, \{2\}, \{3\}, \{4\}, \{5\}, \{6\} \)
\(2^6 = 64\)
Jet d'un dé de quatre faces (tétraèdre) \(\Omega = \{1, 2, 3, 4\}\) \(n = 4\)
  • Lister les événements élémentaires : \(\{1\}, \{2\}, \{3\}, \{4\} \)
\(2^4 = 16\)
Jet d'une pièce \(\Omega = \{P, F\}\) \(n = 2\)
  • Lister tous les événements : \(\varnothing, \{P\}, \{F\}, \Omega \)
\(2^2 = 4\)
Jet de deux pièces \(\Omega = \{PP, PF, FP, FF\}\) \(n = 4\)
  • Lister tous les événements : \( \begin{align} &\varnothing,\{PP\}, \{PF\}, \{FP\}, \{FF\}, \\ &\{PP, PF\}, \{PP, FP\}, \{PP, FF\}, \{PF, FP\}, \{PF, FF\}, \{FP, FF\}, \\ &\{PF, FP, FF\}, \{PP, FP, FF\}, \{PP, PF, FF\}, \{PP, PF, FP\}, \Omega \end{align} \)
\(2^4 = 16\)
Jet de trois pièces \( \Omega = \left\{ \begin{array}{l} PPP, \\ PPF, PFP, FPP, \\ PFF, FPF, FFP, \\ FFF \end{array} \right\} \) \(n = 8\) \(2^8 = 256\)

Tirer une boule \(\Omega = \{1, 2, 3, 4\}\) \(n = 4\) \(2^4 = 16\)
Tirer deux boules successivement sans remise \(\Omega=\left\{ \begin{array}{l} (1,2),(1,3),(1,4),\\ (2,1),(2,3),(2,4),\\ (3,1),(3,2),(3,4),\\ (4,1),(4,2),(4,3) \end{array} \right\}\) \(n = 12\) \(2^{12} = 4\ts096\)
Tirer deux boules successivement avec remise \(\Omega=\left\{ \begin{array}{l} (1,1),(1,2),(1,3),(1,4),\\ (2,1),(2,2),(2,3),(2,4),\\ (3,1),(3,2),(3,3),(3,4),\\ (4,1),(4,2),(4,3),(4,4) \end{array} \right\}\) \(n = 16\) \(2^{16} = 65\ts536\)
