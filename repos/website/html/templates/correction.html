Exercice 1

Soit \(f : \R \to \R\) définie par \(f(x) = x^2 - 3x + 2\).

  1. Calculer \(f(0)\), \(f(1)\) et \(f(3)\).

    On calcule directement :

    $$ f(0) = 0 - 0 + 2 = 2, \quad f(1) = 1 - 3 + 2 = 0, \quad f(3) = 9 - 9 + 2 = 2. $$

  2. Résoudre \(f(x) = 0\).

    On factorise : \(f(x) = (x-1)(x-2)\). Donc \(f(x) = 0 \iff x = 1\) ou \(x = 2\).

  3. Déterminer le minimum de \(f\).

    La parabole a son sommet en \(x_s = -\tfrac{b}{2a} = \tfrac{3}{2}\).

    Le minimum vaut : $$ f\!\left(\tfrac{3}{2}\right) = \tfrac{9}{4} - \tfrac{9}{2} + 2 = -\tfrac{1}{4}. $$
